# AI 工具内容改版

补充定位（2026-10-30）：在工具教程之外加入科技周边新闻，涵盖AI产品更新、模型、芯片、机器人、智能设备及相关产业。每轮最多20个官方文档页面候选及10条新闻候选，工具内容优先交错选稿。新闻采用自然段，不强制功能编号；必须具备最近24小时发布时间、当前正文和配置媒体署名，保留事实归属。新闻与教程共用排期、限额和跨形式主题去重。原有工具稿继续有效，不因扩展定位取消。

按用户提供的十部分规范改造现有微头条自动流程，排期、账号、声明、限额及不可重复提交保护保持现有规则。

1. 新增 AI 工具编辑配置及独立成稿服务：聚焦一个产品或工作流，标题进入发布正文，编号条目，250～600字为建议，结尾3～5个标签。参考资料仅保存在草稿来源中。
2. 官方页面联网读取替代头条热点改写：配置用户列出的产品官方文档入口，轮换选取产品，读取可访问的官方正文及同产品文档。无法读取、事实不清楚时少发；不把产品主页链接当作证据。每轮至多检查30个页面候选。
3. 生成、一次有界删改及发布前检查共用写作规范；向模型提供近期标题，检查产品辨识度、数字条数、入口、版本/套餐限制、虚构实测与重复模板。只允许经过本轮实际联网读取的官方资料支持的断言。
4. 独立保存官方URL、正文及核实时间；发布前再次读取官方页，比较重要变化。永久来源及正文去重继续有效。官方文档不要求24小时内发布，明确区分核实时间和发布时间。
5. 切换时取消未提交的旧定位稿件并跳过其对应时段；其余未来时间点用于新稿，不修改排期、不补发过去时段。保留旧稿、历史回执、数据库备份，更新页面说明及文档，同步已有仓库。

实施步骤：先写格式、来源边界、官方刷新与旧稿隔离测试并观察失败；实现编辑器/官方采集模块及运行器适配；执行回归和真实只读采集/生成验证；空闲部署并恢复原有自动模式。真实验证不增加额外发布或绕过检查。
